# Web Development Project

## What Happens After Entering a URL?

When we enter a URL in a web browser and press Enter, the browser first uses DNS (Domain Name System) to find the IP address of the server where the website is hosted. Then, the browser sends a request to that server to access the webpage. The server responds by sending website files such as HTML, CSS, JavaScript, and images. HTML provides the structure of the webpage, CSS styles its appearance, and JavaScript adds interactivity. Finally, the browser processes these files, displays the content, applies the styles, and runs the scripts to render the complete webpage on the screen.
